# Menu og områder

Appens funktioner er bevaret, men fordelt efter formål.

## Opsætning

- **Scene:** scene, roller og scenens grundvalg.
- **Partner:** identitet, udseende, alder og AI-billeder.
- **Indhold:** personlighed, intensitet, udstyr, tøj, temaer, ord og grænser.
- **Opgaver:** intervalbaserede og gentagne opgaver.
- **Frue:** Frue-funktioner og heldagsplan med faste klokkeslæt.
- **Privatliv:** chatnavn, lagring, notifikationsvisning og panikfunktion.

Den faste bjælke nederst viser den valgte scene og partner og starter scenen.

## Chat

Chatten har én **Menu**-knap. Sidepanelet indeholder:

- Tilpas scene
- Startside
- Regler
- Noter og lyd
- Tilgængelighed og notifikationer
- Safeword og scenestatus

## Opgavetyper

- **Intervalopgaver** sender efter den valgte rytme og det valgte antal.
- **Heldagsplan — faste tider** sender de valgte Frue-opgaver på de angivne
  klokkeslæt, også som Web Push når appen er lukket, hvis brugeren har slået
  Til rådighed til.
